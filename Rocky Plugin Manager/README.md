# Rocky Idle Plugin Manager

This release is meant to stay in one folder:
- RPM.exe
- plugins\

## How to use
1. Put your .plugin files into the plugins folder.
2. Run RPM.exe.
3. Click Locate Game Folder and select your Rocky Idle install.
4. Install plugins from the manager.

## Updating after game updates
1. Open RPM.exe.
2. Uninstall the plugin.
3. Reinstall the plugin.

If a game update changes game files, uninstall/reinstall is the safe way to re-apply patches.
