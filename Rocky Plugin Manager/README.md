# Rocky Idle Plugin Manager

This release is meant to stay in one folder:
- RPM.exe
- plugins\

## How to use
1. Download any .plugin files from the repository root.
2. Put those .plugin files into this folder's plugins folder.
3. Run RPM.exe.
4. Click Locate Game Folder and select your Rocky Idle install.
5. Install plugins from the manager.

## Updating after game updates
1. Open RPM.exe.
2. Uninstall the plugin.
3. Reinstall the plugin.

If a game update changes game files, uninstall/reinstall is the safe way to re-apply patches.
